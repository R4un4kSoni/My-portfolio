# 🌌 Raunak Soni — Cinematic Portfolio Website

A modern cinematic frontend portfolio website built using **HTML** and **CSS**.  
Focused on premium UI design, glassmorphism, responsive layouts, smooth visuals, and clean frontend architecture.

---

# 🚀 Features

- Modern cinematic UI
- Responsive design
- Glassmorphism navbar & cards
- Gradient-based visual identity
- Smooth scrolling
- Animated hero section
- Interactive hover effects
- Clean section-based layout
- Mobile-friendly responsive system

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Flexbox
- CSS Grid
- Responsive Design
- Glassmorphism UI
